4 STEPS

Install BepInEx

Download and install BepInEx into your Gorilla Tag game directory. Run the game once to generate config folders.

02
Download Mod

Click any Download button above to grab the .DLL file for the mod you want.

03
Drop in Plugins

Move the .DLL file into your BepInEx/plugins/ folder inside the Gorilla Tag directory.

04
Launch & Play

Start Gorilla Tag. Your mods will load automatically. Join a private lobby to test safely.
